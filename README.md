# Литературный архитектор 0.1

Рабочая минимальная версия для Windows 10/11. Работает локально, без регистрации.
Для запуска нужен **Python 3.11 или новее**. Дополнительные библиотеки не нужны.

## Запуск без навыков программирования

1. Установите Python с https://www.python.org/downloads/windows/ . В установщике
   включите **Python Launcher** и **Add Python to PATH**.
2. Распакуйте весь архив в обычную доступную для записи папку, например
   «Документы → Литературный архитектор». Не запускайте из окна архива.
3. Дважды щёлкните **START_WINDOWS.bat**. Откроется окно запуска и браузер.
4. Если браузер не открылся, введите в адресной строке **http://127.0.0.1:8765**.
5. Нажмите «Открыть рукопись» и выберите DOCX, TXT или EPUB до 20 МБ.
6. Посмотрите вкладки «Структура», «Персонажи», «Аудит». Нажмите ссылку на
   абзац для перехода к исходному фрагменту.
7. Для завершения закройте окно запуска. Одна закрытая вкладка браузера
   не останавливает приложение.

Если порт занят, закройте ранее запущенную копию. Для другого порта можно
открыть терминал в папке и выполнить `py -3 app.py --port 8766`.

## Глубокий аудит и художественная редактура

Откройте «Модель». Укажите базовый URL OpenAI-совместимого сервера (обычно
заканчивается на `/v1`), точный идентификатор модели и при необходимости ключ.
Для LM Studio запустите локальный сервер и загрузите модель; стандартный адрес
`http://localhost:1234/v1`. Для Ollama с совместимым API —
`http://localhost:11434/v1`. Доступность и качество зависят от выбранной модели.
Облачные API используют HTTPS; локальные серверы могут использовать HTTP.

Выберите один из четырёх режимов, подтвердите передачу рукописи и запустите
анализ. Ключ не записывается на диск. Адрес, ключ и модель нужно ввести заново
после ухода со вкладки. При облачном провайдере текст покидает компьютер;
возможна тарификация. Без модели доступен только эвристический аудит.
При ошибке API частичный результат не сохраняется, книгу это не изменяет.

На вкладке «Аудит» сравните исходную цитату и предложенную редакцию. Кнопка
«Подтвердить замену» запросит подтверждение. Только после него изменится текст.
На вкладке «История» можно последовательно отменять последние правки.
Предложения, принятые ранее, после отмены помечаются устаревшими: выполните
новый анализ. «Текст → Скачать текущую книгу DOCX» экспортирует текущую версию.

## Хранение и восстановление

В папке `data` находятся база `library.sqlite3`, исходники `originals` и
резервные копии `backups`. Скопируйте всю папку `data` на внешний диск,
предварительно закрыв приложение. Перед принятием/отменой правки и изменением
канона база резервируется автоматически. Чтобы восстановить автоматическую
копию: закройте приложение, сохраните текущую `library.sqlite3` отдельно и
скопируйте выбранный файл из `backups` на её место с именем `library.sqlite3`.
Автоматического удаления резервных копий нет: контролируйте свободное место.

## Что реализовано и каковы ограничения

- Импорт DOCX/TXT/EPUB; главы по заголовкам и сцены по отбивкам.
- Карточки-кандидаты локально; подробные описания с источниками через модель.
- Статистика, график объёма глав, переходы к абзацам, постоянный канон книги.
- Четыре режима API, порционный анализ с накопленным резюме и каноном.
- Подтверждение и сравнение правок, история, отмена, SQLite backup, экспорт DOCX.

Это не готовая замена профессиональному редактору. Проверки сюжетных дыр,
исторической точности, психологии и стиля выполняет подключённая модель;
её выводы требуют проверки. Локальные кандидаты в персонажи — эвристика
по прописным буквам без морфологии. Автоматического графа отношений,
выделения сюжетных линий, общей базы серии, поиска по всем книгам и отдельной
хронологической шкалы пока нет. Канон каждой книги можно вести вручную.
Очень длинный одиночный абзац не режется и может превысить контекст модели.
Резюме предыдущих порций не сохраняет все детали всей книги. Источники
проверяются на совпадение цитаты, но это не доказывает истинность вывода.

DOCX импортирует текст абзацев (включая таблицы); оформление, картинки,
сноски, комментарии и Track Changes не сохраняются. Экспорт создаёт новый
текстовый DOCX. EPUB без DRM, по порядку spine, UTF-8. TXT: UTF-8 или CP1251.
Первоначальный файл сохраняется отдельно без изменений.

Приложение слушает только 127.0.0.1. Данные хранятся без шифрования; права
доступа определяет ваша учётная запись Windows. Не публикуйте локальный порт.
Не закрывайте приложение и не переключайте книги во время анализа.

## Проверки для разработчика

`python -m unittest -v` — тесты импорта, сегментации, сохранения, правок,
backup, проверки ссылок ответа модели и последовательности EPUB.
`python app.py --no-browser` — запуск без открытия браузера.
Архитектура и план расширения: ARCHITECTURE.md.

Проверено в Linux на Python 3.12; Windows-пакет подготовлен, но на реальной
Windows в этой среде не запускался. Готовый EXE в эту поставку не входит.
